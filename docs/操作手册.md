# 具体操作手册（照着做）

> 全程只需要：手机 + 一个 GitHub 账号 + 一台能跑 fastboot 的电脑。
> 现在工作区里已有的东西：`boot.img`（原厂 boot）、`sukisu-polaris/`（仓库）、`sukisu-polaris-repo.zip`。

---

## 第 1 步：在 GitHub 建一个空仓库

手机浏览器打开 **https://github.com/new**

| 字段 | 填什么 |
|---|---|
| Repository name | `sukisu-polaris` |
| Description | `polaris MIUI12 SukiSU nova kernel` |
| 可见性 | `Public`（私有仓库也能跑 Actions，但免费额度少） |
| 初始化选项 | **全部不勾**（不要 README / .gitignore / license） |

点绿色 **Create repository**。建好后页面停在空仓库提示页，地址形如
`https://github.com/你的用户名/sukisu-polaris`

---

## 第 2 步：拿一个 PAT（只做一次）

浏览器打开 **https://github.com/settings/tokens/new?scopes=repo,workflow&description=sukisu-polaris**

- Note：`sukisu-polaris`
- Expiration：`30 days` 就行
- 勾选：`repo`（整组）+ `workflow`

页面拉到底 → **Generate token** → 复制 `ghp_xxxxxxxx`（只显示一次，先存到便签）。

---

## 第 3 步：把仓库推上去（手机里直接推，不需要电脑）

DSH 终端里执行（把三处大写占位换掉）：

```bash
cd /sdcard/dsh-work6/sukisu-polaris

git init -b main
git add .
git -c user.name="$(git config --global user.name || echo polaris)" \
    -c user.email="$(git config --global user.email || echo me@example.com)" \
    commit -m "init: polaris MIUI12 SukiSU build"

git remote add origin https://<你的用户名>:<ghp_xxx>@github.com/<你的用户名>/sukisu-polaris.git
git push -u origin main
```

成功标志：输出里出现 `main -> main` 且没有 `rejected`。

> 推完建议立刻执行一次 `git remote set-url origin https://github.com/<用户名>/sukisu-polaris.git`，把 token 从 remote 里摘掉。
> 不想推整目录也行，用网页 `Add file → Upload files` 拖文件，但 **`.github/workflows/build.yml` 是隐藏目录，网页拖拽经常漏掉**，漏了 Actions 就找不到 workflow，所以推荐 git 推。

---

## 第 4 步：触发构建

1. 打开 `https://github.com/<用户名>/sukisu-polaris/actions`
2. 左侧点 **build-sukisu-polaris**
3. 右侧 **Run workflow** 按钮下拉，参数按下表填（其余保持默认）：

| 参数 | 填 |
|---|---|
| kernel_repo | `unknownbaka/utopia_kernel_polaris` |
| kernel_branch | `main` |
| defconfig | `stock_defconfig` |
| ksu_setup_arg | `builtin-new` |
| enable_tamper | ✅ 勾上 |
| enable_susfs | ⬜ 不勾 |
| enable_kpm | ⬜ 不勾 |
| repack_boot | ✅ 勾上（仓库里没放 boot.img 时会自动跳过，不报错） |

点绿色 **Run workflow**。刷新页面能看到一条正在跑的记录（黄色圆点）。

耗时 **20~40 分钟**。跑的时候不用守着，会通知失败邮件（如果开了）。

---

## 第 5 步：看结果

- 绿勾 ✅ → 点进那次运行，页面**最下面** `Artifacts` 区域 → **kernel-artifacts** 下载，得到一个 zip。
- 红叉 ❌ → 点进去，展开红的那一步，把**最后 60 行**贴给我，我改完给你新的 workflow 文件（改 yml 不需要重推全部，网页直接编辑提交即可）。

zip 里的内容物：

```
Image.gz          ← 你要的
Image
used.config       ← 实际生效的配置，重点看有没有 CONFIG_KSU=y
SHA256SUMS.txt
boot.log
boot_sukisu.img   ← 只有仓库放了 boot.img 才有
```

---

## 第 6 步：把产物弄回手机

浏览器下载的 zip 通常在 `/sdcard/Download/`。DSH 终端里：

```bash
cd /sdcard/dsh-work6
cp /sdcard/Download/kernel-artifacts.zip .    # 文件名按实际下载的
unzip -o kernel-artifacts.zip -d artifacts/
ls -l artifacts/
```

确认 `artifacts/Image.gz` 存在。用 `cat artifacts/used.config | grep CONFIG_KSU` 检查：
必须看到 `CONFIG_KSU=y` 和 `CONFIG_KSU_TAMPER_SYSCALL_TABLE=y`，没有就说明集成没生效，别刷。

---

## 第 7 步：合成可刷 boot

```bash
cd /sdcard/dsh-work6
cp boot.img sukisu-polaris/boot.img
cd sukisu-polaris
./scripts/build_boot_local.sh ../artifacts/Image.gz
```

预期输出（关键三行）：

```
[+] 原 boot: header_v1 page=4096 kernel=44282080 (b'gzip') ramdisk=810223 ...
[+] 已写出 boot_sukisu.img ... sha256=...
[OK] 校验通过：ramdisk/cmdline/地址与原厂一致，仅内核被替换
```

如果看到 `!! 校验失败` 就停，别刷，把输出发我。

---

## 第 8 步：刷机

电脑装好 platform-tools（`adb` / `fastboot`），手机开 USB 调试（设置 → 关于手机 → 连点 MIUI 版本 7 次 → 开发者选项 → USB 调试）。

```bash
adb devices                       # 先确认能看到设备序列号
adb push /path/boot_sukisu.img /data/local/tmp/   # 直接把文件拷到电脑上也行
adb reboot bootloader             # 或关机后 音量下 + 电源
fastboot devices                  # 必须能看到序列号，否则驱动没装好
fastboot flash boot boot_sukisu.img
fastboot reboot
```

刷入成功后第一次开机比平时慢（1~3 分钟），**别中途长按电源**。

---

## 第 9 步：装管理器 + 验证

1. 手机浏览器打开 **https://git.zako.shirkneko.top:20004/shirkneko/SukiSU/releases**
2. 下载最新的 `SukiSU_*.apk` 安装（允许未知来源）
3. 打开，首页应显示已安装/工作中
4. 终端里验证：

```bash
adb shell su -c id        # 期望: uid=0(root) gid=0(root) ...
adb shell dmesg | grep -i ksu | head
```

5. 给一个普通 App（如 MT 管理器、Termux）点授权，弹框能出现就说明权限链通了。

---

## 第 10 步：出问题就回滚（30 秒）

```bash
# 进 fastboot 后：
fastboot flash boot boot.img
fastboot reboot
```

`boot.img` 就是工作区里那份原厂镜像。**刷之前先把它备份到电脑/网盘**，别只留在手机上。

按现象分诊见 [troubleshooting.md](troubleshooting.md)，或者直接把日志贴给我。

| 轮次 | kernel_repo | kernel_branch | defconfig |
|---|---|---|---|
| 1（默认） | unknownbaka/utopia_kernel_polaris | main | stock_defconfig |
| 2 | unknownbaka/utopia_kernel_polaris | main | polaris_defconfig |
| 3 | avantgarde280/kernel_xiaomi_polaris-miui | LA.UM.8.3.r1-05800-sdm845.0 | sdm845-perf_defconfig |

第 3 轮是“版本号完全对齐但你那台不一定点亮”的对照组，只在前两轮都失败时用。
